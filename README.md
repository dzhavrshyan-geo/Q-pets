# Q-pets — питомец для QGIS

Небольшое окошко с обезьянкой, которая работает вместе с вами в QGIS.

![Q-pets](docs/screenshot.png)

Чем занят питомец:

| Когда | Что делает |
|---|---|
| вы печатаете | стучит по клавиатуре (иногда с размаху по Enter), на мониторе заполняется таблица атрибутов |
| работаете мышкой | водит мышкой и щёлкает, карта на его мониторе двигается |
| крутите колёсико | крутит колёсико, карта на мониторе приближается и отдаляется |
| Ctrl+S | показывает большой палец и подмигивает, на мониторе «Сохранено» |
| Ctrl+Z | «ой!» — хлопает себя по лбу |
| QGIS долго рисует карту или считает инструмент | барабанит пальцами, потом ждёт, скрестив руки, и вздыхает «…» |
| ничего не нажимаете (до 15 с) | работает без нажатий: читает экран, подпирает голову, чешет затылок, всматривается в монитор, пишет на стикере, разминает шею |
| 15 с простоя | свои дела: смотрит в окно, сидит в телефоне, пьёт кофе, потягивается, ест банан, читает распечатку, делает селфи, отдыхает, закинув руки за голову, отмечает дело в списке на доске, — и два любимых дела |
| 3 мин простоя | дремлет; от первого нажатия просыпается |
| щелчок по питомцу | машет рукой |

Считаются только действия внутри QGIS (в любом его окне), кроме самого окошка питомца.
За окном в кабинете день, вечер или ночь — по часам компьютера.

## Питомцы

| Питомец | Любимые дела |
|---|---|
| Бантик и тигрёнок | гладит тигрёнка; дразнит его игрушкой на верёвочке. Печатая, от усердия высовывает язык |
| Розовая кепка | подпирает щёку и мечтает под музыку; танцует на стуле |
| Шимпанзе в галстуке | чешет подбородок, пока не придёт идея; запускает бумажный самолётик через весь кабинет |

## Установка

1. Собрать архив: `python tools/build_zip.py` → `dist/q_pets.zip` (в архиве папка `q_pets`).
   Или скачать репозиторий и положить папку `q_pets` в папку модулей QGIS
   (Windows: `%APPDATA%\QGIS\QGIS3\profiles\default\python\plugins`).
2. QGIS → «Модули» → «Управление и установка модулей» → «Установить из ZIP».
3. При первом запуске окошко появится в правом нижнем углу QGIS.

Работает в QGIS 3.16 и новее (в том числе QGIS 4 на Qt6), Windows / Linux / macOS.

## Окошко

- Это обычная панель QGIS: её можно перетащить в любое место, прикрепить к боковой панели
  или к вкладкам рядом со «Слоями». QGIS запоминает, где она была, и при следующем запуске
  откроет её там же. Окошко всегда поверх QGIS и сворачивается вместе с ним.
- Внизу: выбор питомца, **⚙** — настройки (через сколько секунд простоя отдыхать: 10/15/30/60,
  дремать ли после 3 минут), **▾** — свернуть окошко до полоски, **▴** — развернуть.
- Закрыть окошко можно крестиком, вернуть — кнопкой с обезьянкой на панели модулей
  или «Модули → Q-pets». При каждом запуске QGIS питомец открывается сам; чтобы он
  не появлялся совсем, отключите модуль.
- Пока окошко скрыто или свёрнуто, анимация не идёт и ресурсы не тратятся.

## Устройство

| Файл | Что внутри |
|---|---|
| `q_pets/plugin.py` | панель в QGIS, отслеживание клавиатуры/мыши и занятости QGIS |
| `q_pets/pet_widget.py` | окошко: сцена и нижняя панель с настройками |
| `q_pets/brain.py` | поведение: когда работать, когда ждать, когда отдыхать |
| `q_pets/animation.py` | анимации: позы по времени и плавные переходы между ними (руки — мягкие дуги, локоть свисает сам или ставится явно) |
| `q_pets/drawing.py` | рисование кабинета и питомцев (всё векторное, без картинок) |
| `q_pets/pets.py` | описание питомцев: цвета, одежда, вещи на столе, любимое дело |

Чтобы добавить питомца, допишите его в `pets.py`; его любимые дела (`specials`) —
анимации из `animation.py` (словарь `ACTIVITIES`). Новое общее занятие достаточно
добавить в `ACTIVITIES` и в список `FOCUS` (работа без нажатий) или `IDLE_COMMON` (свои дела).

## Разработка

Нужен Python с PyQt5 (`pip install PyQt5`), QGIS для этого не нужен:

```
python -m unittest discover tests      # тесты (поведение, рисование, плагин с заглушкой QGIS)
python tools/preview.py out            # кадры всех анимаций: out/sheet_*.png
python tools/make_icon.py              # перерисовать q_pets/icon.png
python tools/build_zip.py              # dist/q_pets.zip для установки
```
